# Resultados derivados

- `modelos/`: parámetros, Ts, estructura del modelo, región de validez y ensayos
  usados para identificación y validación.
- `figuras/`: gráficas con unidades, condición y procedencia; distinguir simulación
  de medición y guardar el comando/script que las reproduce.
- `metricas/`: métricas por ensayo y resumen por condición y velocidad inicial.

Versionar las evidencias finales. Conservar las fuentes crudas en `experimentos/`;
no guardar mediciones inventadas ni sustituirlas con señales simuladas.
